Condr is a small desktop app for running Claude Code, Codex, and other CLI agents in one window.

- **Always on** — The `condr` Server stays on. Close the window or disconnect. Your agents keep working.
- **Remote access** — Manage local and remote machines in one window. Connect over SSH or pair over TCP.
- **Agent awareness** — See every agent's status in the sidebar. Get a notification when one finishes.
- **Agent driven** — Agents can use Condr too: create panes, read output, assign tasks, and talk to other agents.
- **Real terminals** — Condr uses the `alacritty` core. Every pane gets a real terminal. Run any CLI agent or terminal program.
- **Fast** — Built entirely in Rust. No Electron. Small, fast, and responsive, even while agents are busy.

## Install

> [!WARNING]
> Condr is in early development. Packages ship with each `dev` tag. Client and Server must use the same build.

Download installers from [Releases](https://github.com/condrdev/condr/releases).

### Desktop

| Platform            | Package  |
| ------------------- | -------- |
| Linux x86_64 / arm64 | AppImage |
| macOS x86_64 / arm64 | `.pkg`   |
| Windows x86_64      | `.exe`   |

### Headless server

| Platform            | Install command                              |
| ------------------- | -------------------------------------------- |
| Linux x86_64 / arm64 | `curl -fsSL https://condr.dev/install.sh \| sh` |
| macOS x86_64 / arm64 | `curl -fsSL https://condr.dev/install.sh \| sh` |
| Windows x86_64      | `irm https://condr.dev/install.ps1 \| iex`     |

Click **Connect Remote Device** in the sidebar to add a remote connection:

```text
ssh://user@build-box                         # uses your OpenSSH config and ssh-agent
tcp://<server key>.<invite>@<host>:<port>    # generated by `condr server invite`
```

- Once `condr` is installed on the remote device, SSH forwards its private socket directly, with no additional configuration.
- TCP endpoints use static keys for mutual authentication (`Noise_IKpsk2`). Invites are valid for 10 minutes.

**Note:** TCP is off by default. Start the Server with `--listen` to enable it.

## Development

```bash
git clone https://github.com/condrdev/condr
cd condr
cargo build
cargo run -p condr-gui                   # needs a display (Windows / macOS / Linux desktop)

cargo fmt --all -- --check
cargo clippy --workspace --all-targets --features condr-gui/test-support -- -D warnings
cargo test --workspace --features condr-gui/test-support
```
