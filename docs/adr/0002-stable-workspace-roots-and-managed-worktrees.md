# Stable Workspace Roots and Managed Worktrees

Condr keeps each Workspace Root Directory stable instead of deriving its identity from a live Pane cwd. A Root Directory is an absolute path interpreted and validated by the owning Server: the GUI uses a native directory picker for a local endpoint and Server-path text input for a TCP or SSH-tunnel endpoint. Git metadata is optional and derived, while permission to remove a checkout comes only from explicit Managed Worktree state created by Condr. Close Workspace affects runtime state only; Remove Worktree is separate, refuses dirty or untracked files, and does not delete the branch. This gives folder-oriented GUI identity and conservative deletion semantics at the cost of not following Herdr's dynamic identity, parent-group close cascade, or forced worktree removal.
