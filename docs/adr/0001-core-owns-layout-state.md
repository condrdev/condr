# Core Owns Layout State

`condr-core` owns stable Session, Workspace, Tab, and Pane identities plus the Tab split layout; `condr` projects the active layout into gpui-component Dock. Dock runtime IDs, tab stacks, and serialized state are not domain or persistence truth because their lifecycle does not expose every close/focus transition and tying saved state to GPUI would violate the standalone server boundary; GUI layout mutations therefore route through the server protocol and Dock remains a replaceable view.

The GUI may retain a lazy Dock projection per Server/Tab to preserve GPUI entities across navigation, but only the active projection is mounted or rendered. Inactive projections are a presentation cache: authoritative Bootstrap state prunes them when Tabs disappear, and a Server/runtime/Session identity change clears them. Optimistic layout projection is request-correlated and remains provisional until a Bootstrap covers the matching reliable layout event sequence; rejection or connection loss discards it.
