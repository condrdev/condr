# The GUI Checks for Updates

The GUI asks GitHub every five hours whether the Update Channel it follows has published a build newer than itself, and says so; it never downloads or installs anything. Condr publishes on two channels, both already in place: `stable`, the immutable `v*` releases `release.yml` marks Latest, and `nightly`, the mutable prerelease `nightly.yml` recreates at `main`. A third, prerelease `v*-rc` tags, is left until a release candidate is actually needed: it needs `release.yml` to publish such tags as prereleases, the Windows and macOS packages to strip the suffix from their numeric version fields, and `compare_builds` to order prerelease versions.

The Settings About page has three rows for it; the first two are keys of `[client.updates]`, beside `[client.terminal]`. "Check automatically", `auto_check`, is on unless turned off; off, Condr makes no request unless asked. "Update channel", `channel`, is `stable` or `nightly`; unset, it follows the build: `build.yml` sets `CONDR_RELEASE` to `1` for a release and `0` for a nightly, the GUI reads it at compile time, and a local `cargo build`, which has neither, counts as stable. The person may switch either way; switching changes only what the check looks for, since the package on disk stays what it is. "Check now" has a Check button that checks right away, whether or not the automatic checks are on.

Each channel compares one thing. Stable reads `tag_name` from `releases/latest` and calls it newer when `compare_builds` says the other side's version is higher, so a nightly of the released version is not offered its own release. Nightly reads the commit of `git/ref/tags/nightly` and calls it newer whenever it differs from this build's `CONDR_BUILD_COMMIT`: the tag only moves forward along `main`, and a commit comparison needs no second request. A build without a commit therefore always sees the nightly as newer. Automatic checks run five seconds after start and then every five hours, a fixed schedule: turning them on starts it with a check, a channel change checks the new channel at once outside it, and a Check leaves it alone. An answer that arrives after its channel was changed is dropped. Unauthenticated GitHub API calls allow 60 an hour per address, far above this. An automatic check's failure, whether no network, a rate limit or an unexpected answer, is logged at `warn` and waits for the next one: nobody asked for it, so it is not a failed operation to show (ADR 0020). A Check was asked for, so its failure is a `report_error` toast, its button spins while the request runs, and a check that finds nothing newer says "Condr is up to date." under it.

A newer build puts a dot on the sidebar's Settings button and a row on the About page naming it, `Condr 0.2.0` or `Nightly <12-character commit>`, whose View button opens that release's page, where the person picks a package. Neither can be dismissed and nothing is stored: the dot stays until the installed build catches up, the channel changes or automatic checks are turned off. No toast and no OS notification, since an update never needs attention now.

Only the GUI checks. It and the local Server are one package, so it speaks for the installation; a remote Device's build difference is already marked through the handshake (ADR 0027), and the headless `condr` is updated by rerunning the install script, whose default is now the latest stable release rather than the nightly. The HTTP client is GPUI's own `ReqwestClient` from `gpui-pre-reqwest-client`, which Kit builds but does not re-export, so the GUI declares it directly, the one exception to declaring only `gpui-kit`. `startup::run` builds it off the main thread, since loading the platform's CA certificates is not free, and sets it as the App's HTTP client; tests never run `startup::run`, so they keep GPUI's test client, which answers 404, and never reach GitHub. It is built through `proxy_and_user_agent`, whose preconfigured TLS installs a crypto provider, because iroh's ring and the client's aws-lc-rs are both in the build and rustls cannot pick one on its own. Proxies follow reqwest's system proxy detection, the `HTTPS_PROXY` family included.

Tests: the decision per channel, a higher version on stable and any other commit on nightly, and unknown channel names following the build; against GPUI's fake HTTP client, an automatic check's failure staying quiet, a Check's failure reported, the automatic checks repeating five hours on and finding a newer release, turning them off forgetting it, and a Check still working while they are off. Nothing reaches GitHub.
