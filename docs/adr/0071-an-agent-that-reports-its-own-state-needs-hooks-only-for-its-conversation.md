# An Agent That Reports Its Own State Needs Hooks Only for Its Conversation

Status: accepted 2026-11-19. Amends ADR 0035, which knew two levels, and ADR 0044, which left the level to an Agent's hooks.

ADR 0044 made an Agent's Program Status Protocol reports, OSC 7501, its state from the first one on, and still decided its level by its hooks: they alone carry the session ID a restart resumes with. An Agent whose reports are right but whose hooks fire a subagent's Stop as its own therefore stayed recognized only, unresumable and refused by `agent wait`, though Condr shows its state. A survey on 2026-11-19 found that this describes most of the CLIs Condr could add next: Kimi Code 2.6 and Goose 1.60, which an OpenAI-compatible endpoint can test, and Factory Droid, Kiro and Devin, which need their vendors' accounts. What their hooks cannot say, their reports already do: only the root record, the report without `id`, is the Agent.

A third level joins the two: an Agent **fully supported through its own reports**. Its CLI reports its root record over OSC 7501 with an `app` that resolves to it, and a hook names its conversation: a session start carrying the native ID that a subagent does not fire, or that says when it belongs to one. Condr installs that hook, and its events only name the conversation: they never set the state, before the first report or after it. Until the Agent reports it is `Unknown`. `agent wait` and `agent prompt --wait` accept it, and a restart resumes it, as for any fully supported Agent. Where its reports cannot reach Condr, from a release that predates them or through a probe that loses to conhost's DA1 on a Windows Server (ADR 0044), it stays `Unknown` rather than showing what its hooks would get wrong; its note names the release that reports.

The level is `AgentSupport::ProgramStatus`, beside `Full` and `RecognitionOnly`, and like them it follows from the spec. The documentation lists these Agents with the fully supported ones, saying their state comes from the Agent itself. Kimi Code moves to it from recognized only, and Goose joins at it.
