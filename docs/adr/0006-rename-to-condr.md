# Rename to Condr

The product name changes from Murmur to **Condr**. Macroscope's Murmur (macroscope.com/murmur) is an enterprise platform for orchestrating fleets of AI coding agents supporting Claude Code and Codex — a direct competitor in the same category — so the Murmur name is unusable regardless of legal risk. Condr contracts "conductor" in the same dropped-vowel style as herdr: herdr names the shepherd, condr names the conductor who directs many performers, which matches the product's orchestration role. Availability was verified on 2026-08-30: crates.io `condr` and `condr-core` are unregistered, and the only GitHub uses are an inactive 2016 student project and a gist. Known tradeoffs are accepted: the name reads as part of the herdr naming family, and search results share noise with conda/.condarc typos, Netflix Conductor, and HTCondor.

Runner-up candidates, kept in case Condr becomes unusable before release: **kodama** (Mononoke tree spirits; legally usable but the crates.io `kodama` name is taken by a clustering library and kodama.ai belongs to a forestry robotics company) and **zugzug** (Warcraft peon voice line; fully unregistered but opaque to non-gamers). Rejected earlier for conflicts in or near the agent-tooling space: boids (boids.so), waggle (Argonne platform plus an agent MCP tool), wisp (usewisp.ai), mure (mureai.com), parvi (parvi.ai), peon (peon.dev, OpenPeon), takt (nrslib/takt is an AI agent orchestration CLI), maestro, cadence, foreman, helm, tempo, cue, and fugue.

The repository, crates (`condr-core`/`condr-server`/`condr`), binaries, docs, and protocol naming adopt the Condr name atomically. The project is unreleased, so no compatibility aliases or migration path are retained for old Murmur identifiers or state locations.
