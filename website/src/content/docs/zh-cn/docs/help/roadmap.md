Condr 0.1 正处于公开预览阶段。本页列出后续准备开发的功能，排列顺序即为开发顺序，不承诺具体交付日期。如果想推动某项进展或提出新需求，请在 [GitHub Issues](https://github.com/condrdev/condr/issues) 中说明你的具体使用场景。

---

## 接下来

### 1. 更多官方支持的 Agent CLI

Condr 将官方支持更多常见的 Agent CLI，每个 Agent 都按[支持级别](/zh-cn/docs/using/agents/#支持级别)标明完整支持还是仅识别。如果你常用的 CLI 还不在列表中，欢迎提交 Issue 或 PR。

### 2. 终端内搜索

支持在当前 Pane 的终端缓冲区中搜索，包括已滚出可视区域的内容。匹配项会自动高亮，并支持跳转定位。

### 3. 手机端（iOS 与 Android）

离开电脑时，可通过手机查看各设备上的 Workspace、Agent 状态、Needs you 列表以及只读的终端画面。当 Agent 完成任务或需要人工介入时，手机会收到推送通知。推送内容由 Server 使用手机公钥端到端加密，中转推送的服务器以及 Apple 和 Google 均无法解密。

手机端支持扫码配对，仅通过 Peer-to-peer 或 TCP 连接设备，不支持 SSH 连接。手机端能执行哪些操作目前仍在设计中。

### 4. 端口探测与转发

Agent 在 Workspace 中启动 dev server 后，Condr 会在对应的 Workspace 和 Pane 上标出其监听的端口。对于经由 SSH 连接的设备，点击端口即可转发至本机并在浏览器中打开。

### 5. GitHub 集成

Workspace 将展示当前分支关联的 GitHub PR、PR 状态及 CI 检查结果，点击可直接在浏览器中查看。支持输入 PR 编号或链接，将该 PR 检出为独立的 Managed Worktree。PR 合并后，Condr 会提示清理对应的 worktree，但不会自动删除。

创建、合并及评审 PR 仍交由 Agent 与 `gh` 处理。

## 等待更多反馈

以下事项已纳入考量，但需要更多实际使用场景作为支撑才会正式排期。如果你有相关需求，请在 Issue 中补充你的工作流细节。

- **从 Diff Tab 跳到编辑器**：支持在 Diff Tab 中直接调用外部编辑器打开当前文件。
- **在 GUI 中启动 Agent**：列出设备上已安装的 Agent，点击即可在 Pane 中启动。
- **定时任务**：按预设时间启动 Agent，或定时向运行中的 Agent 投递提示词。
- **TCP 与 Peer-to-peer 设备的端口转发**：将第 4 项的端口转发能力扩展至非 SSH 连接的设备。

## 更远的计划

以下方向已在规划中，但排在上述所有事项之后，且需要满足对应的前置条件才会启动。

| 事项 | 启动条件 |
| :--- | :--- |
| 团队协作与权限管理 | 出现多人共用同一个 Server 的真实需求 |
| 编辑器 | 审查改动时经常需要顺手修改代码，而远程设备上的文件无法通过 Open in 在本机编辑器中打开 |
| 内置浏览器 | 端口转发上线后，在系统浏览器和 Condr 之间来回切换仍是常见的不便 |
| 任务看板 | 同时进行的任务多到侧栏和 Needs you 列表已经看不过来 |

---

## 不做

- **Web 客户端**：Condr 坚持原生桌面体验，不把控制界面移植到浏览器。离开电脑时的需求由 Peer-to-peer 连接和手机端承载。
- **自建对话界面**：Condr 专注于编排原生的 Agent CLI，不重写对话循环，亦不绑定任何特定模型供应商。输入框、模型选择及语音交互均交由各 CLI 自行处理。
- **自定义 Agent**：Condr 只集成官方支持的 Agent CLI，不提供通过配置文件或插件接入其他 CLI 的方式。因为每种 CLI 的状态都要靠专门编写并实测过的 Hook 集成才可信。需要支持新的 CLI，请提交 Issue 或 PR。
