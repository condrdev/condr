---
title: 改动与文件预览
description: 在 Condr 中快速查看 Agent 修改的文件、对比代码差异（Diff）以及预览项目文件。
---

当 Agent 修改或重构代码时，你需要快速确认改动了哪些文件以及改动是否正确。Condr 内置了文件改动与预览视图，也能直接对文件做简单修改，无需打开外部 IDE 即可完成审查。

## 打开改动面板 (Changes)

- **快捷键**：按下 `Cmd + Option + B` (macOS) 或 `Ctrl + Alt + B` (Windows/Linux)。
- **界面入口**：点击右侧栏标题栏的侧栏按钮打开。

改动视图会根据 Git 状态将修改的文件分为三组：
- **Conflicts**：存在合并冲突的文件。
- **Tracked**：已追踪并被修改的文件。
- **Untracked**：Agent 新建但尚未纳入 Git 追踪的文件。

每一个文件后都会标出新增和删除的行数，列表上方比较对象按钮那一行的右端汇总累计变动行数。

列表会自动跟随磁盘上的变化。如果某次没跟上，比如项目在网络盘上，点击侧栏右上角的 **Refresh**，让 Device 重新扫描这个 Workspace；Files 和当前打开的 diff 也会一起刷新。

## 对比 HEAD 或 base 分支

改动列表上方的按钮写着当前的比较对象，例如 `Against main`，点开菜单可以改选：

- **HEAD**：只列出尚未提交的改动。Agent 提交之后，这些文件就会从列表中消失。
- **base 分支**：菜单里显示分支名，例如 `main`。列表包含这条分支从分叉点以来的全部改动，已提交和未提交的都在内，base 分支后来新增的提交不会列入。

Condr 新建 Worktree 时，会把父 Workspace 当时所在的分支记为 base 分支。其他 Workspace 依次使用远端的默认分支（例如 `origin/main`）、本地的 `main` 和 `master`。当前分支本身就是 base 分支或它的上游时，只能对比 HEAD。

每个 Workspace 分别记住自己的选择。

## 查看代码差异 (Diff)

1. 在 **Changes** 列表中点击任意文件，中间区域会自动打开 **Diff** 标签页。
2. 页面会以高亮形式展示该文件相对于所选比较对象的具体改动，标题栏会标出比较对象，例如 `Against main`。
3. **Split**（两栏图标）把新旧文件左右并排显示，**Unified**（两行图标）把它们合在一栏里。标题栏里的这个选择对所有 Diff 标签页生效，并会被记住。
4. 没有改动的大段内容会折叠起来，点击折叠行可以向上、向下展开更多行，或全部展开。
5. 点击标题栏的 **Show File**，会在 Preview 标签页中打开该文件，并定位到你在 diff 中最后点击的那一行。

> **提示**：极大的二进制文件或单文件超过 1 MiB 时，出于性能保护会自动隐藏明细对比。

## 浏览提交历史 (History)

把右侧栏切到 **History**，可以看到 Workspace 当前分支的提交记录，最新的在最上面，顺序和 `git log` 一致：

- **每一行**显示提交标题、短 ID、作者和提交时间。Agent 提交后，新提交会自动出现在最上面。
- **点击提交**会在提交列表下方的区域列出它改动的文件，以及每个文件新增和删除的行数；拖动两块之间的分隔线可以调整大小，再次点击该提交即可收起。点击文件，会在 Diff 标签页中打开该提交对这个文件的改动；标题栏下方显示提交标题，点旁边的箭头可以展开完整的提交说明。
- **复制提交 ID**：在 Diff 标签页的标题栏或提交的右键菜单中都可以复制。
- 列表末尾的 **Show more** 会再加载 100 条提交。

History 只读取仓库，不会检出、回滚或创建提交。在 **Changes** 中点击文件，Diff 标签页会回到工作区的改动。

## 浏览项目文件与预览 (Files & Preview)

- **切换至文件树**：在右侧栏顶部将标签切至 **Files**，即可像文件管理器一样展开和浏览项目文件夹。
- **改动标记**：有修改的文件夹旁会带有一个圆点标记，被 `.gitignore` 忽略的文件会自动变灰。
- **点击预览**：点击任意文本文件即可在 **Preview** 标签页中打开。文件在磁盘上发生变化时，语法高亮与滚动位置会自动刷新。
- **Markdown 与图片渲染**：Markdown 与 SVG 文件默认以渲染后的效果打开，可在 Tab 顶部的 **Preview** 与 **Source** 间随时切换。常见格式图片（PNG、JPEG、GIF、WebP、BMP、ICO、TIFF，约 2 MiB 以内）会自动缩放适应窗口，动图可直接播放。Markdown 中的图片仅支持加载项目本地文件，网络图片则显示其替代文字。

## 编辑文件 (Preview)

Preview 标签页的 **Source** 视图就是一个编辑器，在本地和远程 Device 上均可使用：

- **编辑与保存**：直接修改文件内容，然后按 `Cmd + S` (macOS) 或 `Ctrl + S` (Windows/Linux) 保存。Tab 顶部的圆点表示有未保存的改动。Condr 不会自动保存，改动只在你保存时写入文件，不会趁 Agent 写文件时自动覆盖。
- **保留换行符**：使用 Windows 换行符（`CRLF`）的文件，新增的行也会沿用 `CRLF`。
- **文件在磁盘上被改动时**：你还有未保存的改动时，如果 Agent 写入了该文件，你的文本会保持不变，顶部会显示 **Changed on disk**。此时保存会询问是用当前文本 **Overwrite**（覆盖），还是 **Discard and Reload**（放弃改动并重新加载）。
- **未保存的改动不会被静默丢弃**：在切换到其他文件、关闭 Tab 或退出 Condr 之前，Condr 都会先询问是否保存。若另一台设备切换或关闭了该 Tab，你仍然可以选择保存、复制或放弃当前文本。
- **只读文件**：非有效 UTF-8 文本、二进制文件以及超过 1 MiB 的文件只能查看、无法编辑，顶部会说明原因。

## 快捷右键菜单

在 Changes 或 Files 列表中的文件上右键，可选择以下常用操作：

- **Open in ...**：选择用本地已安装的 VS Code、Zed、Cursor 或 IntelliJ IDEA 打开当前文件或项目。
- **Insert Path into Terminal**：快速将文件的相对路径粘贴到最近使用的终端窗格中，方便传给命令行工具。
- **Copy Relative Path / Copy Path**：一键复制文件相对路径或绝对路径。
- **Reveal in Finder / Reveal in File Explorer / Open Containing Folder**：在系统文件管理器中显示该文件或文件夹（仅限本地 Device）。
- **New File… / New Folder…**：在 Files 视图中创建条目：可在文件夹内新建、在文件旁同级新建，或在文件树下方的空白处新建到项目根目录。新文件会在 Preview 标签页中打开，可直接输入。
- **Rename…**：在所在文件夹内重命名文件或文件夹，若名称已被占用则会拒绝。
- **Delete…**：确认后删除文件，或删除文件夹及其全部内容。删除是永久性的，不进入系统回收站。

Condr 不会改动 `.git` 里的任何内容。
