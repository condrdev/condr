Condr 客户端负责界面渲染与交互，终端会话、Agent 进程和窗口布局均由后台 Server 托管。关闭窗口不会终止正在运行的会话。

## 窗口布局

Condr 界面划分为四个功能区：

### 顶部标题栏

| 控件 / 状态 | 功能说明 |
| :--- | :--- |
| **侧栏开关** | 折叠或展开左侧栏。折叠状态下仅保留 Workspace 缩写图标。 |
| **Tab 标签栏** | 显示当前 Workspace 下的所有标签。点击 `+` 从当前 Pane 所在目录启动新 Shell。 |
| **Open in** | 在外部编辑器或文件管理器中打开项目根目录（仅支持本地设备，自动记录每个项目的选择）。 |
| **右侧栏开关** | 展开或收起右侧栏，状态按 Workspace 独立保存。 |
| **Viewing only** | 提示当前设备已被另一 Condr 窗口独占接管。此时界面为只读状态，禁止操作。 |

---

### 左侧导航栏

管理设备、项目工作区及 Agent 状态。支持直接拖拽设备或 Workspace 调整排序。

* **Needs you**：待处理提醒列表。当 Agent 需要确认或人工输入时置顶显示，点击可直达对应 Pane。
* **设备与连接**：
  * **设备卡片**：按设备分组管理工作区（本地显示为 `Local`）。右键菜单支持连接、断开，远程设备还支持编辑或删除。
  * **状态图标**：🔴 红色表示未连接（点击重连）；⚠️ 黄色三角表示设备运行的 Condr 版本与当前窗口不一致。
  * **Connect Remote Device**：位于底部，支持通过 SSH、TCP 或 P2P 连接远程设备。
* **Workspace（工作区）**：
  * 显示项目图标、名称与 Git 分支（非仓库显示 `no git`）。
  * 状态标识：分支落后/超前上游时标注提交数（`↑N ↓N`）。
  * 右键菜单：支持重命名、新建 Git Worktree 或关闭工作区。
* **Agent 状态列**：按工作区归类列出所有 Agent，图标角标反映实时生命周期。
* **辅助工具**：
  * 底部咖啡图标：一键保持屏幕常亮（防休眠）。
  * 底部齿轮图标：系统设置（有新版本可用时显示红点）。

---

### 主操作区（Tab 与 Pane）

* **终端 Tab**：每个 Tab 可容纳一组多窗格分屏（Pane）。标签带有序号，支持快捷键直达。
* **审查 Tab（Diff / Preview）**：
  * 从右侧栏单击文件唤起，分别用于比对差异和预览源码。
  * 每个 Workspace 最多各有一个审查 Tab，查看下一个文件时复用，避免标签泛滥。
* **Pane 窗格控制**：
  * **标题栏**：显示 Agent 标识、终端标题与放大/还原按钮。
  * **⋮ 操作菜单**：包含拆分、交换、最大化与关闭操作。
  * **布局调整**：拖拽 Pane 标题栏至另一个 Pane 的中央可交换位置，拖至边缘可拆分并停靠；拖拽 Pane 之间的分隔线调整窗格大小。

---

### 右侧信息栏

* **Files（项目树）**：浏览项目目录结构。有修改的文件夹显示圆点，被 `.gitignore` 忽略的文件置灰显示。单击即可在 Preview Tab 中查看。
* **Changes（文件改动）**：仅在 Git 仓库下激活。按 `Conflicts`（冲突）、`Tracked`（已追踪）、`Untracked`（未追踪）分类展示修改文件与增删行数。单击在 Diff Tab 中审查改动。
* **快捷右键菜单**：支持快速复制相对/绝对路径、直接插入路径到终端或在本地编辑器中打开。

## Agent 状态指示

Agent 运行状态集中展示在**左侧栏角标**、**Workspace 计数器**及 **Needs you** 区域。

| 状态标识 | 状态说明 |
| :--- | :--- |
| **Working** | 正在执行任务（推理思考、生成文本或调用工具）。 |
| **Blocked** | 阻塞状态，等待用户输入或授权（在 Needs you 中列出）。 |
| **Done** | 后台执行完毕。当焦点切回该 Pane 时自动重置为 Idle。 |
| **Idle** | 空闲状态，当前轮次完成，等待新指令。 |
| **Unknown** | 原生 Shell 会话，或未接入 Condr Hook 的 Agent。 |
| **Bell** | 终端发出响铃提醒（Bell 优先级高于常规生命周期状态）。 |

> **提示**：当处于后台的 Agent 完成任务或触发阻塞时，Condr 会推送系统原生通知，点击直接定位至相应窗格。要启用状态跟踪，请参阅 [Agent 集成文档](/zh-cn/docs/using/agents/)。

## 欢迎页

设备已连通但尚未打开任何 Workspace 时显示，提供 **Open Project** 和 **Connect Remote Device** 快捷入口。

## 连接状态

* **未加载工作区时**：居中显示连接步骤、错误排查提示及重试按钮。
* **已加载工作区时**：Pane 顶部显示状态栏，重连开始后的 2 秒内不显示。
* **断线期间**：Server 保持后台执行，网络恢复后无缝恢复窗口上下文与输出。

## 命令行集成 (CLI)

`condr` 命令行提供窗口大部分功能的接口，支持在脚本自动化与 Agent 工具调用中执行：

| 命令组 | 操作对象 |
| :--- | :--- |
| `condr workspace` | 管理工作区生命周期：创建、重命名、聚焦、列出或关闭。 |
| `condr tab` | 管理标签页：新建、重命名、切换与关闭。 |
| `condr pane`（布局控制） | 分屏、移动、调位、尺寸缩放与聚焦。 |
| `condr pane`（I/O 控制） | 写入按键/命令、捕获并读取窗格回显。 |
| `condr agent` | 检索可用 Agent、安装 Hook、在 Pane 中启动 Agent、发送提示词并等待执行结果。 |
| `condr device` | 列出已保存的远程设备及其连通性。 |
| `condr server` | 管理本地 Server 守护进程（启动/重启/配对管理）。 |

### 作用域规则
* **在 Pane 终端中执行**：默认绑定当前 Workspace、Tab 与 Pane，无需提供上下文 ID。
* **在系统默认终端执行**：直接连接本地 Server，需显式传入操作对象的 ID。
* **远程操作**：附加 `--device <设备名>` 参数（`server` 和 `agent hooks` 等宿主级命令仅限本地执行）。

## 推荐阅读路径

初次使用建议按以下路径配置工作流：

1. **环境与布局**：阅读 [Workspace、Tab 与 Pane](/zh-cn/docs/using/workspaces/)，掌握分屏与 Worktree 隔离开发。
2. **接入 Agent**：查阅 [Agent 集成](/zh-cn/docs/using/agents/)，安装 Hook 启用状态同步。
3. **文件与代码审查**：查阅 [改动与文件预览](/zh-cn/docs/using/changes/)，进行增量审查与 Diff 比对。
4. **进阶实践**：
   * 需远程开发，查阅 [远程连接](/zh-cn/docs/using/remote/)（SSH / TCP / P2P）。
   * 需多 Agent 协同，查阅 [Agent 自动化](/zh-cn/docs/using/automation/)。
   * 常用快捷键与外部编辑器，查阅 [快捷键与偏好设置](/zh-cn/docs/using/preferences/)。
