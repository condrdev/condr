在多机、多环境（本地笔记本、远程 GPU 开发机、云端构建机）之间进行重度 AI 编程时，现有的工具链往往陷入两难：

- **笨重的 Remote IDE**：启动远程 VS Code / JetBrains Gateway 动辄消耗数百兆内存与高额 CPU，网络稍有抖动便界面卡死，配置开销极大。
- **原始的纯终端流（SSH + tmux）**：虽然足够轻量稳定，但缺乏直观的代码审查视图（Diff / Preview）、不支持多端并发协作，也无法统一管理分布在各台设备上的 Agent 状态。
- **被锁在 Webview 里的 AI**：多数工具将 Agent 强行塞入 IDE 聊天框，既丢掉了命令行生态的灵活性，又无法摆脱图形 IDE 的资源包袱。

Condr 为打破这种割裂而生：**它是一个极致轻量、启动毫秒级、专为跨设备 Agent 协同打造的现代化工作台。**

---

## 核心优势与设计

### 1. 极致轻量与极速响应（Lightweight & Fast）

摒弃 Electron 与繁重的全功能远程开发环境，Condr 基于纯 Rust 全栈打造：

- **极低系统资源开销**：服务端 `condr-server` 与客户端 `condr-gui` 均编译为紧凑的原生机器码，常驻内存占用极小，服务器几乎无额外性能负载。
- **毫秒级冷启动与 60Hz 渲染**：基于纯 Rust 虚拟终端内核，在 Agent 动态输出、批量刷屏或超长回滚缓冲区场景下依然保持帧率稳定，交互毫无粘滞感。
- **即开即连**：无需在远端拉起庞大的语言服务器或守护集群，数秒内即可完成配对与终端就绪。

### 2. 现代化的跨设备直连（Modern Remote Connectivity）

Condr 将“随时随地无缝连入任意机器”作为一等公民能力构建：

- **零配置穿透（P2P 直连）**：基于 Iroh 协议与 Relay 辅助打洞，即便本地与远端均处于复杂内网或 NAT 之后，无须公网 IP 或配置端口映射也能建立点对点直连。
- **金融级安全通道**：内置基于 Noise 协议的双向加密认证，配合一次性配对码与单设备 Ed25519 密钥，免去繁琐的证书与密钥分发维护。
- **全通道兼容**：同时完整支持原生 SSH 套接字转发与本机 Unix Domain Socket / 命名管道，无缝融入既有运维体系。
- **多端独立视角**：两台设备同时连入同一台远程 Server 时，各自独立浏览不同的工作区与标签页，配合主从只读保护（Viewing only），兼顾协作与输入安全。

### 3. 服务端常驻运行时（Server-Owned Runtime）

彻底摆脱“关窗掉线、断网丢会话”的脆弱体验：

- **进程与窗口彻底解耦**：所有终端会话、Agent 进程与长耗时任务均由常驻的 `condr-server` 托管。关闭桌面应用只是关闭画面投影，后台任务永不中断。
- **拓扑结构平滑恢复**：Server 实时持久化布局快照。即便重启守护进程，也会自动重建工作区分屏结构，并重新接续已有上下文。

### 4. 终端优先，100% 保留原生 Agent 生态（Terminal-First）

Condr 不做二手聊天界面，不接管对话循环，也不代发 API 请求：

- **原生子进程直通**：Claude Code、Codex、OpenCode 等 CLI 原汁原味运行在系统真实 PTY 中。
- **完整生态支持**：无缝保留各厂商原生的上下文压缩、本地配置、权限提示与丰富交互。
- **开箱即用的审查面板**：无需切换到完整 IDE，即可通过轻量的 Diff Tab 与 Preview Tab 直观审查 Agent 产出的每一处代码变更。

## 常见方案对比

| 考量维度 | 远程重型 IDE（如 VS Code Remote） | 经典终端复用器（SSH + tmux） | Condr |
| :--- | :--- | :--- | :--- |
| **性能与资源消耗** | 远端常驻数百 MB 内存，容易卡顿 | 极低（纯字符终端） | **极低（原生 Rust 架构，内存开销极小）** |
| **网络穿透与组网** | 依赖公网暴露、反向代理或隧道工具 | 需自行配置 SSH Jump Host 或 VPN | **内置 P2P 打洞直连，复杂内网零配置互联** |
| **会话持久化** | 依赖远程 Server 状态，掉线偶发异常 | 依赖 tmux 后台守护，纯终端恢复 | **服务端常驻守护，支持窗口与分屏结构恢复** |
| **多端协同视图** | 多人接入同一窗口时强制同步光标与视图 | 共享同一终端画面，操作互相干扰 | **每个客户端独立拥有视图，自带主从防冲突** |
| **代码审查效率** | 功能完整但启动沉重 | 需手动敲 `git diff`，缺乏图形化对比 | **内置轻量语法高亮 Diff 与 Preview 视图** |
| **Agent CLI 原生度** | 多数被引导使用侧边栏扩展，割裂 CLI | 100% 原生运行，但无可视化协同编排 | **100% 原生运行，兼具直观状态呈现与审查** |
